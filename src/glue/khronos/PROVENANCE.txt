Verification
------------

Fetch each file from the repository and commit recorded above, then compare
its SHA-256 hash with this table. No Coin-specific changes are permitted in
these vendored files; local integration belongs outside this directory.

When updating the snapshot, update the commits, blob IDs, hashes, generated
header versions, and import date together.
