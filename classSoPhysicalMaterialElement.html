Detailed Description

Reserved element for a physically based material.

Carries the metallic-roughness parameters of the shape currently being traversed. It is unset (enabled == FALSE) by default, which keeps the traditional Blinn-Phong appearance; a producer node (for example Gui::SoFCPbrMaterial) sets it for materials that carry authored metalness and roughness.
